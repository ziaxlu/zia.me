# zia.me

A small static portfolio site.

## Local preview

From the project root, run:

```bash
python3 -m http.server 8000
```

Then open this in a browser:

```text
http://localhost:8000
```

To stop the local server, press `Ctrl+C` in the same terminal window.

This project is a static site, so it is best viewed through a local web server instead of opening the HTML files directly in a browser.
